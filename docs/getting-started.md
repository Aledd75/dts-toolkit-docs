# Primeiros Passos

Esta página ajuda você a colocar o Dadalt Tech Toolkit para rodar com segurança e com o menor atrito possível.

## Requisitos básicos

- Windows 10 ou Windows 11, x64.
- Execução com privilégios de Administrador.
- Internet para validação de Trial, ativação e recursos que dependem de confirmação online.
- Uso portátil, sem instalação tradicional no sistema.

## Como iniciar

1. Baixe o executável pela distribuição oficial.
2. Execute o arquivo como Administrador.
3. Se o Windows exibir alerta de segurança, confirme se o download veio da origem oficial antes de continuar.
4. Ao abrir, confira o status de Trial ou ativação no próprio Toolkit.

## O que esperar na primeira abertura

- Verificação do estado de licença.
- Inicialização da interface principal.
- Disponibilização dos módulos de manutenção, diagnóstico e suporte.
- Exibição dos logs ou mensagens operacionais relevantes para a sessão.

## Boas práticas

- Mantenha o sistema de destino dentro dos requisitos de suporte do produto.
- Use o Toolkit em máquinas com autorização de atendimento.
- Consulte a área de licenciamento antes de repetir a ativação em um novo ambiente.
- Se algo parecer bloqueado, veja primeiro a [Solução de Problemas](troubleshooting.md) e a [FAQ](faq.md).
