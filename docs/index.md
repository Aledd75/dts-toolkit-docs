# Bem-vindo ao DT Toolkit

O **DTS Toolkit (Dashboard Edition)** é uma solução "Tudo-em-Um" portátil desenvolvida pela **Dadalt Tech Solutions** para manutenção, otimização e diagnóstico avançado de computadores Windows.

![Dashboard Preview](dashboard.png){ width="100%" }

## Principais Recursos

* **🚀 Manutenção Automática:** Limpeza de disco, reparo de Windows Update e otimização de SSD com um clique.
* **🗑️ Deep Uninstaller:** Remoção de softwares com limpeza forense de registros e arquivos residuais.
* **🛡️ Segurança:** Hardening do Windows Defender, bloqueio de telemetria e gestão de políticas (GPO).
* **🔧 Reparo de Boot:** Ferramentas para recriar BCD, MBR e WinRE.
* **📦 Gestão de Apps:** Instalação em massa via Winget e remoção de Bloatwares do Windows.

## Por que usar?

O sistema foi projetado para técnicos de TI e usuários avançados que precisam de agilidade. Ele não requer instalação e roda diretamente como um executável portátil, mantendo logs detalhados de todas as operações.
