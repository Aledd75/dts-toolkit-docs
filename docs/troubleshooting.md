# Solução de Problemas

Esta página reúne orientações práticas para os casos mais comuns no uso do Dadalt Tech Toolkit.

## A interface parece parada ou demora para responder

Em tarefas mais pesadas, o Toolkit pode estar executando uma operação em segundo plano.

- Aguarde a conclusão da tarefa atual.
- Verifique a área de logs do próprio aplicativo.
- Evite abrir várias ações pesadas ao mesmo tempo.

## O Windows pediu permissão de administrador

Isso é esperado para módulos que mexem com manutenção, reparo e ajustes avançados.

- Execute o arquivo como Administrador.
- Se necessário, ajuste as propriedades do executável para abrir sempre com elevação.

## O Trial ou a ativação não concluiu

Quando a validação depende de internet, uma falha de conexão pode interromper o processo.

- Confirme se o dispositivo está online.
- Verifique se a data e hora do sistema estão corretas.
- Consulte a página de [Licenciamento, Trial e Ativação](licensing.md).

## O antivírus sinalizou alerta

Ferramentas que executam manutenção profunda do Windows podem receber falso positivo em alguns cenários.

- Confira se o download veio da origem oficial.
- Leia a seção de [Perguntas Frequentes](faq.md).
- Siga o suporte oficial antes de adicionar exclusões permanentes.

## Um módulo de rede não aplicou a mudança como esperado

- Verifique se o adaptador está ativo.
- Confirme se a máquina não depende de uma política corporativa mais restritiva.
- Refaça a ação após validar a conectividade básica.
