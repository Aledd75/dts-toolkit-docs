# Sistema & Reparo

Resumo rápido da área de manutenção do Windows.

## O que cobre

- Rotinas de limpeza e verificação.
- Correções ligadas à inicialização.
- Apoio a otimizações e recuperação de componentes essenciais.

## Quando usar

- Quando o Windows está lento ou instável.
- Quando o problema está no boot.
- Quando o atendimento pede uma sequência clara de reparo.
