# Como protegemos seus dados

**Aviso de Privacidade v1.0**

O Dadalt Tech Toolkit trata dados de forma proporcional ao uso do produto, à validação de licença e ao suporte ao cliente. Esta página explica o que pode ser coletado, para quê, e quais são os seus direitos.

## Quais dados coletamos

Podemos coletar apenas os dados necessários para operar e dar suporte ao produto, como:

- informações fornecidas por você em contato com suporte;
- dados de licença, Trial e ativação;
- identificadores técnicos mínimos necessários para validação e prevenção de uso indevido;
- registros operacionais e de erro usados para diagnóstico e estabilidade.

## Para que usamos os dados

- Validar Trial, ativação e estado da licença.
- Prestar suporte técnico.
- Manter a estabilidade e a segurança do serviço.
- Diagnosticar falhas e melhorar a documentação pública.

## O que não coletamos

- Não coletamos conteúdo dos seus arquivos pessoais para fins de marketing.
- Não coletamos senhas para armazenamento permanente.
- Não coletamos dados além do necessário para a finalidade informada.
- Não vendemos dados pessoais.

## Compartilhamento

- Não compartilhamos seus dados com terceiros para fins publicitários.
- Podemos usar provedores necessários para funcionamento, suporte ou obrigações legais.
- Quando houver processamento de pagamento por canal externo, ele segue as regras do provedor responsável.

## Segurança

- Adotamos o princípio do menor acesso necessário.
- Limitamos o uso dos dados ao que é útil para a operação e o suporte.
- Mantemos cuidado com informações sensíveis e com os registros técnicos gerados no uso do produto.

## Retenção

- Os dados são mantidos apenas pelo tempo necessário para a finalidade informada.
- Quando possível, os registros são retidos por período compatível com suporte, auditoria operacional e obrigações legais.
- Após esse período, a eliminação ou anonimização pode ser aplicada conforme a necessidade.

## Direitos do usuário

Você pode solicitar, conforme aplicável:

- acesso aos seus dados;
- correção de informações;
- exclusão quando cabível;
- esclarecimentos sobre tratamento e retenção.
